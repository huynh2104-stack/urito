# 日本語UI用語集（D-04）

Urito の日本語画面（`src/i18n/ja.ts`）で統一して使用する用語と表記ルールを定義する。

## 統一用語表

| 概念 | 統一日本語表記 |
|---|---|
| POS画面・販売画面 | レジ |
| 精算・支払処理 | お会計 |
| カートの仮保存 | 保留 |
| 会計済み・未会計データ | 取引（一覧: 取引履歴） |
| 一部・全額の返金 | 返品・返金 |
| 会計の取り消し | 取消 |
| 商品・伝票の割引き | 値引き |
| 勤務時間・レジ点検 | シフト、レジ締め |
| シフト中の現金出入 | 入金・出金 |
| ツケ払い・未回収残高 | 掛売り、売掛金 |
| 取扱商品・分類 | 商品、カテゴリー |
| 倉庫数量・数量確定 | 在庫、棚卸 |
| 発注入庫・取引先 | 仕入、仕入先 |
| 会員・還元制度 | 顧客、ポイント |
| 集計・統計 | 売上レポート |

## 文体・表記ルール

1. 通知メッセージ・エラー・空状態の説明文は「です・ます」調で記載する。
2. ボタンやフォーム項目名は体言止め（名詞または動作名詞）を用いる。
3. 数字および英字記号はすべて半角（`10%`, `8%`, `¥1,234`）を使用する。
4. カタカナは全角を使用し、半角カナ（`ｶﾀｶﾅ`）は用いない。
5. 日本語と英数字（例：`CSVでエクスポート`, `Uritoへようこそ`）の間には不要な空白を入れない。
6. 軽減税率対象品には商品名末尾に全角アスタリスク `※` を付し、注記「`※印は軽減税率対象商品です`」を明示する。
